# estoq

Precision in every move. A modern offline-first desktop point-of-sale and inventory management application for clothing retailers: stock control, sales and analytics in one Windows app.

**Stack:** WinUI 3, .NET 10, C#, MVVM (CommunityToolkit.Mvvm), MSIX. The front end is built first on sample data; the SQLite back end follows.

## Status

Plan, checklist and status: [docs/roadmap.md](docs/roadmap.md). Built so far: the app shell.

## Getting started

```bash
dotnet build estoq.sln -p:Platform=x64   # Windows
```
